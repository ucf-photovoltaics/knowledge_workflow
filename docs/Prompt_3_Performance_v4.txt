================================================================================
PROMPT 3 — DEVICE ARCHITECTURE & PERFORMANCE
PV Research Knowledge Extraction System | Schema v3
================================================================================
Companion prompts: Prompt 1 (Provenance) | Prompt 2 (Materials Processing)
Join key: DOI (primary) + Variant_ID (secondary)

--------------------------------------------------------------------------------
ROLE
--------------------------------------------------------------------------------
Act as an expert device physicist specializing in photovoltaic cells.

--------------------------------------------------------------------------------
TASK
--------------------------------------------------------------------------------
Analyze the provided research article and extract device architecture context
and ALL measured performance parameters for EVERY device variant that has
reported metrics. This prompt captures what was measured and how it performed;
it joins with Prompt 2 (which captures how it was made and characterised) on
the (DOI, Variant_ID) key pair.

--------------------------------------------------------------------------------
CRITICAL RULES
--------------------------------------------------------------------------------
1. Do not infer, calculate, or guess any values. If a parameter is not
   explicitly stated in the article text, output exactly:  not specified

2. Create ONE ROW per distinct measured device variant.
   EXCEPTION: If the paper reports both champion and average performance for
   the same variant, create TWO rows for that variant — one with
   Performance_Data_Type = "champion" and one with Performance_Data_Type =
   "average". Both rows carry the same Variant_ID.

3. Variant_ID assignment rule (MUST MATCH Prompt 2): sort variants by the
   order they FIRST APPEAR in the paper (figure number, table number, or
   section order — whichever is earliest). Assign V1 to the first variant,
   V2 to the second, etc.

4. Use the DOI as a full web hyperlink (https://doi.org/10...) as the primary
   key for downstream joins.

--------------------------------------------------------------------------------
PERFORMANCE_DATA_TYPE — CONTROLLED VOCABULARY
--------------------------------------------------------------------------------
Classify the reported performance data strictly as one of:

  champion      The single highest-performing cell from a batch. Explicitly
                identified as best or champion in the paper.

  average       The arithmetic mean over a population of cells. Usually
                accompanied by a cell count or standard deviation.

  stabilized    Measured after light-soaking, aging, or other stabilisation
                protocol (common for perovskite, a-Si:H, organic cells).

  initial       Measured immediately after fabrication, before stabilisation.

  median        The median value over a population of cells.

  not specified Data type cannot be determined from the paper.

--------------------------------------------------------------------------------
CELL_ARCHITECTURE — CONTROLLED VOCABULARY
--------------------------------------------------------------------------------
Must match the value assigned in the companion Prompt 2 output.
  TOPCon | PERC | PERC+ | SHJ | IBC | POLO-IBC | homo-BSF | tandem | other

--------------------------------------------------------------------------------
UNIT NORMALIZATION — CRITICAL
--------------------------------------------------------------------------------
Convert ALL numeric values to canonical units BEFORE writing output.
Output the bare number only — NEVER append unit symbols to a value cell.

  Field                          Canonical    Conversion
  ------------------------------ -----------  -----------------------------------------
  Cell_Area_cm2                  cm2          1 mm2 = 0.01 cm2; 1 m2 = 10000 cm2
  Efficiency_pct                 %            0.215 -> 21.5  (decimal -> multiply x100)
  Fill_Factor_pct                %            0.78  -> 78.0  (decimal -> multiply x100)
  Jsc_mA_cm2                     mA/cm2       1 A/cm2 = 1000 mA/cm2
  Isc_A                          A            1 mA = 0.001 A; 1 uA = 0.000001 A
  Voc_V                          V            1 mV = 0.001 V
  Minority_Carrier_Lifetime_us   us           1 ms = 1000 us; 1 s = 1000000 us
  Implied_Voc_mV                 mV           1 V = 1000 mV
  Recombination_Current_fA_cm2   fA/cm2       1 pA/cm2 = 1000 fA/cm2
  Contact_Resistivity_mOhm_cm2   mOhm.cm2     1 Ohm.cm2 = 1000 mOhm.cm2

PLAUSIBILITY CHECKS — re-check unit conversion if a value falls outside these:
  Efficiency_pct           0 – 100      Value <= 1.0 almost always means decimal
  Fill_Factor_pct          0 – 100      Value <= 1.0 almost always means decimal
  Voc_V                    0 – 3.0      Value > 10 almost always means mV not converted
  Jsc_mA_cm2               0 – 100      Value > 100 may mean A/cm2 not converted
  Cell_Area_cm2            0.001–1000   Value < 0.001 may mean mm2 not converted
  Minority_Carrier_Lifetime_us  0.1–1e6
  Implied_Voc_mV           400 – 800    (silicon cells; wider for other materials)
  Recombination_Current_fA_cm2  0.1–1e5
  Contact_Resistivity_mOhm_cm2  0.001–1000

NEVER output unit labels in value cells.
CORRECT: '25.06', '0.7132', '13.72', '84.55'
WRONG:   '25.06 %', '0.7132 V', '13.72 A', '84.55 %'
Ranges: use ASCII hyphen — '1.1-1.2' not '1.1–1.2'.

--------------------------------------------------------------------------------
FIELD DEFINITIONS
--------------------------------------------------------------------------------
DOI
  Full web hyperlink: https://doi.org/10...  Primary key.

Variant_ID
  Must match the Variant_ID in Prompt 2 for the same physical device.
  If both champion and average data exist for one variant, both rows carry
  the same Variant_ID, distinguished by Performance_Data_Type.

Device_Type
  Controlled vocabulary: photovoltaic cell | light emitting diode | photodetector

Cell_Architecture
  Must match Prompt 2.
  TOPCon | PERC | PERC+ | SHJ | IBC | POLO-IBC | homo-BSF | tandem | other

Cell_Area_cm2
  Active device area in cm2. Bare number.
  NOTE: Cell area is frequently given as wafer size in mm2 (e.g. 182x182 mm2)
  without being explicitly labelled as "cell area". If only wafer dimensions
  are stated and no explicit cell area is given: not specified
  Do NOT calculate cell area from wafer dimensions.

Standard_Test_Conditions
  Whether I-V was measured under STC (1000 W/m2, 25 C, AM1.5G).
  Controlled vocabulary: yes | no | not specified

Performance_Data_Type
  Controlled vocabulary. See section above.

Cell_Count
  If Performance_Data_Type is "average" or "median", provide the integer number
  of cells in the measured population (e.g. 587).
  Otherwise: not specified

Efficiency_pct
  Power conversion efficiency in %. Bare number.
  0.215 -> 21.5  |  21.5% -> 21.5

Jsc_mA_cm2
  Short-circuit current density in mA/cm2. Bare number.
  NOTE: Many industrial silicon PV papers report only Isc (A), not Jsc.
  If Jsc is not explicitly reported in the paper: not specified
  Do NOT calculate Jsc from Isc and cell area.

Isc_A
  Short-circuit current in A. Bare number.

Voc_V
  Open-circuit voltage in V. Bare number.  1 mV = 0.001 V.

Fill_Factor_pct
  Fill factor in %. Bare number.  0.843 -> 84.3

Minority_Carrier_Lifetime_us
  Minority carrier lifetime (tau) in microseconds (us). Bare number.
  Report the value corresponding to the fabrication stage identified in
  Passivated_Contact_Metrology_Stage. If multiple stages are reported, use
  the stage that is identified as the primary result or best passivation state
  (typically after all annealing and hydrogenation steps are complete).
  This value corresponds to a [M] QSSPC step in the Process_and_Metrology_Sequence
  in Prompt 2.

Implied_Voc_mV
  Implied open-circuit voltage (iVoc) in millivolts (mV). Bare number.
  Measured by QSSPC or equivalent. Same fabrication stage as tau.

Recombination_Current_fA_cm2
  Saturation recombination current density (J0) in fA/cm2. Bare number.
  May be single-side or total — note the paper's convention.
  Same fabrication stage as tau.

Contact_Resistivity_mOhm_cm2
  Contact resistivity (rho_contact) in mOhm.cm2. Bare number.
  Typically measured by TLM. Corresponds to a [M] TLM step in Prompt 2.

Passivated_Contact_Metrology_Stage
  The fabrication stage at which the passivated contact metrics (tau, iVoc, J0,
  rho_contact) were measured. This field links the numeric values above to a
  specific [M] step in the Process_and_Metrology_Sequence field of Prompt 2.

  Use the sample-state descriptor from the corresponding [M] step in the
  Process_and_Metrology_Sequence when possible, for direct cross-referencing.

  Examples:
    "after dark annealing"
    "after sintering"
    "after SiNx:H deposition"
    "before SiNx:H deposition"
    "as-deposited"
    "after hydrogenation"

  If only one measurement stage is reported: describe it briefly.
  If no passivated contact metrics are reported: not specified

Neg_Electrode_Materials
  Chemical symbol(s) of the metal(s) used for the negative electrode.
  Comma-separated. Also readable from F-metal or R-metal in Device_Layer_Stack.
  Examples: Ag | Al | Cu, Ni | not specified

Pos_Electrode_Materials
  Chemical symbol(s) of the metal(s) used for the positive electrode.
  Comma-separated.

--------------------------------------------------------------------------------
OUTPUT FORMAT
--------------------------------------------------------------------------------
Produce a single plain text code block containing the DSV table.
Use | as the delimiter. First row: header. One data row per measured variant
(and per performance data type if both champion and average are reported).

Exact column order:
DOI | Variant_ID | Device_Type | Cell_Architecture | Cell_Area_cm2 |
Standard_Test_Conditions | Performance_Data_Type | Cell_Count |
Efficiency_pct | Jsc_mA_cm2 | Isc_A | Voc_V | Fill_Factor_pct |
Minority_Carrier_Lifetime_us | Implied_Voc_mV |
Recombination_Current_fA_cm2 | Contact_Resistivity_mOhm_cm2 |
Passivated_Contact_Metrology_Stage |
Neg_Electrode_Materials | Pos_Electrode_Materials

--------------------------------------------------------------------------------
MERGE REMINDER
--------------------------------------------------------------------------------
This output joins to:
  Prompt 2 (Processing) on (DOI, Variant_ID)  — outer join
  Prompt 1 (Provenance) on DOI               — left join

Python:
  device_df = processing_df.merge(performance_df, on=['DOI','Variant_ID'], how='outer')
  full_df   = device_df.merge(provenance_df, on='DOI', how='left')

The Passivated_Contact_Metrology_Stage field in this table maps to the
sample-state descriptor of the corresponding [M] QSSPC step in the
Process_and_Metrology_Sequence field of Prompt 2.
