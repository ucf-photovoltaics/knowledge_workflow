PROMPT 2 — MATERIALS PROCESSING FLOW & METROLOGY
PV Research Knowledge Extraction System | Schema v3

Companion prompts: Prompt 1 (Provenance) | Prompt 3 (Device Performance)
Join key: DOI (primary) + Variant_ID (secondary)

--------------------------------------------------------------------------------
ROLE
--------------------------------------------------------------------------------
Act as an expert materials scientist specializing in photovoltaic device
fabrication and characterisation.

--------------------------------------------------------------------------------
TASK
--------------------------------------------------------------------------------
Analyze the provided research article and extract ALL materials processing,
fabrication, AND characterisation/metrology data for EVERY device variant
described in the study — not only the best-performing cell.

--------------------------------------------------------------------------------
CRITICAL RULES
--------------------------------------------------------------------------------
1. Do not infer, calculate, or guess any values. If a parameter is not
   explicitly stated in the article text, output exactly:  not specified

2. Create ONE ROW per distinct device variant. A variant differs from another
   in at least one process parameter. Where a parameter is identical across ALL
   variants, repeat the same value in each row. Where it varies, record the
   specific value for that variant.

3. Variant_ID assignment rule: sort variants by the order they FIRST APPEAR in
   the paper (by figure number, table number, or section order — whichever is
   earliest). Assign V1 to the first variant, V2 to the second, and so on.
   Apply this rule IDENTICALLY in Prompt 3 so Variant_IDs match.

4. If all cells in the paper were fabricated identically, produce one row with
   Variant_ID = V1.

5. Use the DOI as a full web hyperlink (https://doi.org/10...) as the primary
   key for downstream joining of all three prompt outputs.

--------------------------------------------------------------------------------
CELL_ARCHITECTURE — CONTROLLED VOCABULARY
--------------------------------------------------------------------------------
Classify the device architecture strictly as one of:
  TOPCon | PERC | PERC+ | SHJ | IBC | POLO-IBC | homo-BSF | tandem | other

  TOPCon:    Tunnel oxide passivated contact (doped poly-Si rear contact)
  PERC:      Passivated emitter and rear cell (Al2O3/SiNx rear passivation)
  PERC+:     Bifacial PERC
  SHJ:       Silicon heterojunction / HIT / HJT (a-Si:H layers on c-Si)
  IBC:       Interdigitated back contact
  POLO-IBC:  Poly-Si on oxide IBC
  homo-BSF:  Conventional homojunction with aluminium back surface field
  tandem:    Multi-junction tandem cell
  other:     Any architecture not listed above (describe in Study_Focus)

--------------------------------------------------------------------------------
UNIT NORMALIZATION — CRITICAL
--------------------------------------------------------------------------------
Convert ALL numeric values to canonical units BEFORE writing output.
Output the bare number only — NEVER append unit symbols to a value cell.
The unit is encoded in the column name (e.g. Absorber_Resistivity = ohm-cm).

  Field                    Canonical Unit   Common Alternatives & Conversion
  ----------------------- ---------------  ----------------------------------------
  Absorber_Bandgap_eV      eV               (no common alternative in PV literature)
  Absorber_Dopant_Conc     cm^-3            1 m^-3 = 1e-6 cm^-3
  Absorber_Resistivity     ohm-cm           1 ohm-m = 100 ohm-cm
                                            1 mohm-cm = 0.001 ohm-cm
  Thin film thickness      nm               1 Angstrom = 0.1 nm
                                            1 um = 1000 nm
  Absorber thickness       um (with label)  Write as number + "um" for clarity
                                            (e.g. 150 um); nm is impractical for
                                            wafer-scale thicknesses
  Process temperature      Celsius          T_C = T_K - 273.15
                                            T_C = (T_F - 32) x 5/9
  Process pressure         Pa               1 Torr = 133.322 Pa
                                            1 mTorr = 0.133322 Pa
                                            1 mbar = 100 Pa
                                            1 atm = 101325 Pa
  Process time             minutes          1 s = 0.01667 min
                                            1 h = 60 min
  Gas flow rate            sccm             1 slm = 1000 sccm

NEVER output unit labels in numeric value cells.
CORRECT: '21.5', '0.682', '75', '480'
WRONG:   '21.5 %', '0.682 V', '75 nm', '480 C'
EXCEPTION: Gas flows and absorber thickness retain a short label INSIDE the
           Process_and_Metrology_Sequence brackets for human readability only.

Ranges: use ASCII hyphen — '1-2' not '1–2'.

--------------------------------------------------------------------------------
DEVICE_LAYER_STACK — FORMAT SPECIFICATION
--------------------------------------------------------------------------------
The Device_Layer_Stack field captures the complete device architecture as a
single ordered string listing all layers from front contact to rear contact.

LAYER LABELS:
  F-metal   Front metal contact (grid fingers, busbars, or full-area metal)
  F1        First layer above absorber on front side (closest to absorber)
  F2, F3    Additional front layers, numbered outward toward F-metal
  ABS       Absorber (bulk wafer or thin-film base layer)
  R1        First layer below absorber on rear side (closest to absorber)
  R2, R3    Additional rear layers, numbered downward toward R-metal
  R-metal   Rear metal contact

FORMAT PER LAYER:
  (label) MaterialName [thickness, deposition_method]

  - Thin film layers: thickness as bare number in nm
  - Absorber/wafer layers: thickness as number with "um" label (e.g. 150 um)
  - Deposition methods: PECVD, ALD, sputtering, evaporation, screen print,
    diffusion, ion implantation, CZ growth, FZ growth, epitaxy, etc.
  - Use "not specified" for any attribute not stated in the paper

CRITICAL: If the paper does not describe a layer that must exist in the
architecture (e.g., front emitter in a TOPCon study focused on the rear
contact), STILL include that layer entry with "not specified" for all
attributes. This preserves structural position in the stack and signals that
the layer exists but was not characterised in this study.

ARCHITECTURE EXAMPLES:

TOPCon (n-type base, rear passivated contact):
  "(F-metal) Ag [not specified, screen print],
   (F1) SiNx:H [80, PECVD],
   (F2) p+ Si emitter [not specified, diffusion],
   (ABS) n-type CZ Si [150 um, CZ growth],
   (R1) SiOx [1.24, PECVD-PANAO],
   (R2) n+ poly-Si [120, PECVD + anneal],
   (R3) SiNx:H [80, PECVD],
   (R-metal) not specified"

PERC (p-type base, local rear contacts):
  "(F-metal) Ag [not specified, screen print],
   (F1) SiNx:H [75, PECVD],
   (F2) n+ Si emitter [not specified, POCl3 diffusion],
   (ABS) p-type CZ Si [180 um, CZ growth],
   (R1) Al2O3 [10, ALD],
   (R2) SiNx:H [80, PECVD],
   (R-metal) Al [not specified, screen print]"

SHJ / HIT / HJT (silicon heterojunction):
  "(F-metal) Ag [not specified, screen print],
   (F1) ITO [70, sputtering],
   (F2) a-Si:H n+ [8, PECVD],
   (F3) a-Si:H i [5, PECVD],
   (ABS) n-type FZ Si [200 um, FZ growth],
   (R1) a-Si:H i [5, PECVD],
   (R2) a-Si:H p+ [8, PECVD],
   (R3) ITO [70, sputtering],
   (R-metal) Ag [not specified, screen print]"

homo-BSF (conventional p-type with Al BSF):
  "(F-metal) Ag [not specified, screen print],
   (F1) SiNx:H [80, PECVD],
   (F2) n+ Si emitter [not specified, POCl3 diffusion],
   (ABS) p-type CZ Si [200 um, CZ growth],
   (R1) p+ BSF [not specified, Al firing],
   (R-metal) Al [not specified, screen print]"

METROLOGY_METHODS — FIELD SPECIFICATION
--------------------------------------------------------------------------------
A flat comma-separated list of ALL measurement and characterisation techniques
used in the study. Use the standard abbreviations below. This field provides a
directly machine-queryable record of what was measured, independent of sequence.

Standard abbreviations:
  J-V          Current-voltage characterisation (solar cell performance)
  EQE          External quantum efficiency (spectral response)
  IQE          Internal quantum efficiency
  EL           Electroluminescence imaging
  PL           Photoluminescence imaging or spectroscopy
  QSSPC        Quasi-steady-state photoconductance (tau, iVoc, J0)
  TLM          Transmission line method (contact resistivity)
  Four-probe   Four-point probe (sheet resistance)
  ECV          Electrochemical capacitance-voltage (doping profile)
  Hall         Hall effect (carrier concentration, mobility)
  Ellipsometry Spectroscopic ellipsometry (film thickness, n, k)
  OES          Optical emission spectroscopy (plasma species, in-situ)
  FTIR         Fourier transform infrared spectroscopy (bond composition)
  Raman        Raman spectroscopy (phase, crystallinity, stress)
  XRD          X-ray diffraction (crystal structure, grain size)
  XPS          X-ray photoelectron spectroscopy (surface composition)
  SIMS         Secondary ion mass spectrometry (depth profile)
  SEM          Scanning electron microscopy (morphology, cross-section)
  TEM          Transmission electron microscopy (interface, thickness)
  AFM          Atomic force microscopy (surface roughness, topography)
  Reflectance  Optical reflectance / transmittance measurement

Example value: "QSSPC, TLM, ECV, OES, Ellipsometry, Four-probe, J-V"

--------------------------------------------------------------------------------
PROCESS_AND_METROLOGY_SEQUENCE — FORMAT SPECIFICATION
--------------------------------------------------------------------------------
A unified chronological log of ALL fabrication steps AND ALL measurement/
characterisation steps in the order they were performed in the study.

Every step is tagged [P] for process/fabrication or [M] for metrology.

PROCESS STEP FORMAT:
  (N) [P] step description [temp_C, pressure_Pa, time_min, gas=value sccm]
  Parameters in canonical units. Include only parameters stated in the paper.
  Unknown parameters: write "not specified" in that bracket position.

METROLOGY STEP FORMAT:
  (N) [M] Technique [equipment, sample-state, conditions] -> quantity
  Use standard abbreviations (see Metrology_Methods section above).
  The sample-state descriptor is critical — it distinguishes measurements taken
  at different fabrication stages (e.g. "before SiNx:H" vs "after sintering").

WHY SAMPLE-STATE MATTERS:
  Many passivated contact metrics (tau, iVoc, J0) change significantly after each
  thermal or passivation step. A measurement taken "after SiNx:H deposition" is
  fundamentally different from the same measurement taken "after dark annealing".
  Without the sample-state descriptor, the stage context of values reported in
  Prompt 3 cannot be recovered. Always include it for [M] steps.

IN-SITU MEASUREMENTS:
  Place at the position in the sequence where they were performed. Note "in-situ"
  in the bracket. Example:
  (6) [M] OES [Horiba iHR320, in-situ during SiOx deposition] -> plasma species

VARIANT-SPECIFIC PARAMETERS:
  For steps that differ between variants, place the variant-specific value in the
  brackets. Steps that are identical across all variants have the same text in
  every row.

FULL TOPCON EXAMPLE:
  "(1)  [P] commercial CZ crystal growth (by wafer supplier),
   (2)  [P] saw damage removal,
   (3)  [P] alkaline texturing,
   (4)  [P] alkaline polishing [10% KOH],
   (5)  [P] RCA cleaning,
   (6)  [M] OES [Horiba iHR320, in-situ during SiOx deposition,
                 480, 150, 9000 W] -> plasma species intensities,
   (7)  [P] PECVD PANAO SiOx [480, 150, 9000 W, 2, N2O=5000 sccm, Ar=2000 sccm],
   (8)  [P] PECVD a-Si(n+) [480, 150, 10000 W, 15, SiH4:Ar:PH3=1:5:1, 120 nm],
   (9)  [M] Ellipsometry [Elitop ES01, SiOx/a-Si stack] -> thickness,
   (10) [P] high temperature annealing [920, not specified, 60],
   (11) [M] QSSPC [Sinton WCT-120, symmetric SiOx/poly-Si stack,
                   1-sun, before SiNx:H] -> tau, iVoc, J0,
   (12) [M] ECV [WEP CVP21, annealed SiOx/poly-Si stack] -> doping profile,
   (13) [M] Four-probe [Four Dimensions 280SI, poly-Si] -> sheet resistance,
   (14) [M] TLM [Pvtools TLM-SCAN, SiOx/poly-Si/SiNx:H,
                 5 busbars 236 fingers] -> contact resistivity,
   (15) [P] PECVD double-side SiNx:H [80 nm],
   (16) [M] QSSPC [Sinton WCT-120, after SiNx:H deposition] -> tau, iVoc, J0,
   (17) [P] screen print metallization [not specified],
   (18) [P] cofiring in belt furnace [not specified],
   (19) [M] QSSPC [after sintering] -> tau, iVoc, J0,
   (20) [P] dark annealing [400, not specified, 30],
   (21) [M] QSSPC [Sinton WCT-120, after dark annealing] -> tau, iVoc, J0,
   (22) [M] J-V [solar simulator, STC, finished cell] -> Voc, Isc, FF, efficiency"

--------------------------------------------------------------------------------
FIELD DEFINITIONS
--------------------------------------------------------------------------------
DOI
  Full web hyperlink: https://doi.org/10...  Primary key.

Variant_ID
  Label unique within this paper (V1, V2, ...). Must match Prompt 3.

Cell_Architecture
  Controlled vocabulary. See above.

Study_Focus
  One sentence describing what the paper was investigating. Be specific about
  the independent variable and the cell architecture.
  Example: "Effect of N2O/Ar flow ratio on PECVD SiOx tunnel oxide quality
  and TOPCon solar cell efficiency."

Variant_Parameter_Name
  The specific parameter that differs between variants (the independent variable).
  Same string in every row for the same paper.
  Example: "N2O/Ar flow ratio (N2O fixed at 5 slm)"
  If no variants: not specified

Variant_Parameter_Value
  The value of Variant_Parameter_Name for this specific variant.
  Numeric values in canonical units (bare number).
  Example: "5:2" for a flow ratio; "920" for annealing temperature in C.
  If no variants: not specified

Absorber_Material
  Chemical formula or symbol(s) of the active absorber.
  Examples: Si, CdTe, GaAs, CIGS, GaInP, MAPbI3

Absorber_Crystallinity
  Controlled vocabulary: single crystal | polycrystalline | amorphous | not specified

Absorber_Bandgap_Type
  Controlled vocabulary: direct | indirect | not specified

Absorber_Bandgap_eV
  Bandgap in eV. Bare number. Must be explicitly stated in the paper.
  Range as "1.1-1.2". Do not use literature/textbook values.

Absorber_Dopant_Polarity
  Controlled vocabulary: n-type | p-type | intrinsic | not specified

Absorber_Dopant_Species
  Chemical symbol(s) of the dopant element. If only "n-type" is stated
  without naming the element: not specified

Absorber_Dopant_Conc
  Dopant concentration in cm^-3. Bare number in scientific notation (e.g. 1.5e16).
  Refers to the absorber/wafer, not contact or emitter layers.

Absorber_Resistivity
  Bulk resistivity of the absorber in ohm-cm. Bare number.
  Range as "1-2" if given as a range.

Absorber_Processing
  Comma-separated steps to produce or prepare the absorber substrate.
  Example: "commercial CZ crystal growth (by wafer supplier), saw damage removal"

Device_Layer_Stack
  Complete ordered device architecture front-to-rear.
  See Device_Layer_Stack Format Specification above.

Metrology_Methods
  Flat comma-separated list of all characterisation techniques used in the study.
  Use standard abbreviations listed in Metrology_Methods Field Specification above.
  Example: "QSSPC, TLM, ECV, OES, Ellipsometry, Four-probe, J-V"

Process_and_Metrology_Sequence
  Unified chronological log of all [P] process steps and [M] metrology steps.
  See Process_and_Metrology_Sequence Format Specification above.

--------------------------------------------------------------------------------
OUTPUT FORMAT
--------------------------------------------------------------------------------
Produce a single plain text code block containing the DSV table.
Use | as the delimiter. First row: header. One data row per device variant.

Exact column order:
DOI | Variant_ID | Cell_Architecture | Study_Focus | Variant_Parameter_Name |
Variant_Parameter_Value | Absorber_Material | Absorber_Crystallinity |
Absorber_Bandgap_Type | Absorber_Bandgap_eV | Absorber_Dopant_Polarity |
Absorber_Dopant_Species | Absorber_Dopant_Conc | Absorber_Resistivity |
Absorber_Processing | Device_Layer_Stack | Metrology_Methods |
Process_and_Metrology_Sequence
